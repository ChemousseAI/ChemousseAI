## ⭐ Research Projects & Publications

### 🩺 Enhancing Diabetic Retinopathy Grading with Advanced Diffusion Models

Research investigating **diffusion models for medical image augmentation** and their impact on diabetic retinopathy grading.

* **Dataset:** IDRiD
* Compared traditional augmentation, DCGAN-based augmentation, and diffusion-based augmentation.
* Evaluated performance using CNN and ResNet50.
* Investigated the use of synthetic medical images generated by diffusion models.
* Presented at **ICICT 2024, London**.
* Published by **Springer**.

📄 [Springer Publication](https://link.springer.com/chapter/10.1007/978-981-97-3559-4_17)

🔬 [ResearchGate](https://www.researchgate.net/publication/382626437_Enhancing_Diabetic_Retinopathy_Grading_with_Advanced_Diffusion_Models)



### ⚡ ProdNet: A Lightweight Network for Fast Discovery of Matrix Multiplication Algorithms

Research project focused on discovering efficient matrix multiplication algorithms using a lightweight neural architecture.

* **2×2 matrix multiplication:** reduced from 8 to 7 multiplications.
* **3×3 matrix multiplication:** reduced from 27 to 23 multiplications.
* Designed with an emphasis on computational efficiency.
* Explores lightweight alternatives for computationally expensive algorithm-discovery approaches.
* Published by **Springer**.

📄 [Springer Publication](https://link.springer.com/chapter/10.1007/978-3-032-21585-7_7)

🔬 [ResearchGate](https://www.researchgate.net/publication/405146798_ProdNet_a_Lightweight_Network_for_Fast_Discovery_of_Matrix_Multiplication_Algorithms)
